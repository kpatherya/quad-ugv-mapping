# Integrations

This directory contains adapted upstream systems and project-specific wiring.
An integration is not assumed to be original algorithmic authorship. Each
subdirectory must identify its upstream project, license, local changes, and
supported runtime in its README or in `docs/PROVENANCE.md`.

`vins_mono_ros2` contains the historical VINS-MONO-ROS2 snapshot used to connect
visual-inertial estimation, TF publication, RealSense depth conversion, OctoMap,
and RViz in the reference ROS 2 Foxy workflow.
